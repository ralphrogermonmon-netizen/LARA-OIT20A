Reflection Questions
1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang Bubble Sort magtan-aw sa magtapad nga numero ug mag-ilis kung dili sakto ang ilang pagkahan-ay. Ang Selection Sort mangita sa pinakagamay nga numero ug ibutang kini sa unahan. Ang Insertion Sort mokuha og numero ug ibutang sa sakto nga pwesto. Lahi sila kay lain-lain ang ilang paagi sa paghan-ay sa mga numero.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay simple ra ang iyang proseso. Magkumpara ra siya og duha ka magtapad nga numero ug mag-ilis sa ilang pwesto kung kinahanglan. Dali ra masabtan kung unsaon niya paghan-ay sa mga numero.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Insertion Sort ang mas maayo kung daan nang han-ay ang mga numero. Kay kung sakto na ang pagkahan-ay, dili na kinahanglan magbalhin-balhin og mga numero. Mubo ra ang iyang trabaho kumpara sa ubang algorithms, basta adunay check aron mohunong kung sakto na ang pwesto.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung magdugang og mga numero sa array, mas daghan na ang kinahanglan susihon ug han-ay. Mas modugay ang paghuman sa sorting kay mas daghan na ang ikumpara ug ibalhin. Ang tulo ka algorithms mahimong mas hinay kung daghan na kaayo ang mga numero.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Importante nga makasabot ta sa lain-laing sorting algorithms kay dili tanan parehas og performance. Isip future programmer, kinahanglan mahibalo ta mopili kung unsang algorithm ang angay gamiton depende sa gidaghanon ug kahimtang sa datos. Makatabang kini aron mas hapsay ug mas paspas ang atong mga programa.
